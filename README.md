# dachadmin-backend

Production-style Dach Admin API for a delivery/logistics admin system using Hexagonal Architecture, `net/http`, PostgreSQL, and `database/sql`.

## Architecture

Dependency direction:

```text
HTTP adapter -> application services -> repository ports + domain
PostgreSQL adapter -> repository ports + domain
```

The domain layer has no imports from `net/http`, `database/sql`, PostgreSQL drivers, JSON request DTOs, or environment configuration. Application services depend on ports, not concrete repositories. HTTP handlers depend on service ports and translate transport concerns only.

UUIDs are generated by PostgreSQL with `gen_random_uuid()` defaults. This keeps repository inserts consistent and avoids mixing ID ownership between Go and the database.

## Requirements

- Go 1.22+
- PostgreSQL
- A migration runner such as `migrate`

## Setup

```sh
cp .env.example .env
```

Create the database, then run migrations:

```sh
migrate -path migrations -database "postgres://postgres:postgres@localhost:5432/dach?sslmode=disable" up
```

Run the API:

```sh
go run ./cmd/api
```

For local sign-in, set these variables before starting the API. The backend creates this team member if it does not already exist:

```sh
BOOTSTRAP_ADMIN_EMAIL=admin@dachcourier.co.uk
BOOTSTRAP_ADMIN_PASSWORD=ChangeMe123!
BOOTSTRAP_ADMIN_NAME="Dach Super Admin"
```

Health checks:

```sh
curl http://localhost:8080/health
curl http://localhost:8080/ready
```

## Authentication

Admin routes require:

```text
Authorization: Bearer <token>
```

Login:

```sh
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"password123"}'
```

Team passwords are stored as bcrypt hashes. API responses never return `password_hash`.

## Example Requests

Create a customer:

```sh
curl -X POST http://localhost:8080/api/v1/customers \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"full_name":"John Doe","email":"john@example.com","phone":"+441234567890"}'
```

List bookings by status:

```sh
curl "http://localhost:8080/api/v1/bookings?status=IN_TRANSIT&page=1&page_size=20" \
  -H "Authorization: Bearer $TOKEN"
```

Assign a driver:

```sh
curl -X POST http://localhost:8080/api/v1/bookings/$BOOKING_ID/assign-driver \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"driver_id":"'"$DRIVER_ID"'"}'
```

Update delivery location:

```sh
curl -X PATCH http://localhost:8080/api/v1/deliveries/$DELIVERY_ID/location \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"latitude":51.5074,"longitude":-0.1278}'
```

Dashboard:

```sh
curl http://localhost:8080/api/v1/dashboard \
  -H "Authorization: Bearer $TOKEN"
```
